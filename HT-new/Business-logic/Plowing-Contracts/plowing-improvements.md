# Plowing Improvement Ideas

## Purpose

This file stores business ideas and improvement notes for plowing functionality in the new HT app.

Use this note for ideas that are not final requirements yet, but may help improve user experience, operations, migration, or support.

## Idea Areas

- Better contract overview for cabin owners
- Clearer plowing status for each cabin
- Better handling of common road contracts
- Better clip card visibility and usage history
- Easier area management for admins
- Better provider assignment and route planning
- Better reporting for migration and data quality

## Possible Improvements

- Show whether a cabin uses `PlowingArea` or `WorkingArea` contract lookup.
- Show common road contract separately from private contract.
- Add warnings when area or contract setup looks inconsistent.
- Add admin view for cabins without valid plowing contract.
- Add data quality dashboard for migrated plowing data.

## Open Questions

- Which plowing problems create most support work today?
- Which contract details should be visible to cabin owners?
- Which plowing data should be visible only to backoffice/admin users?
