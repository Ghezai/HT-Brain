# Activity

This folder documents important activity during the migration process.

Use one markdown file per important activity.

Recommended content:

- activity date
- activity type
- files changed
- table updated
- columns updated
- reason for change
- exact SQL query
- rows affected
- verification query
- notes or mistakes corrected

Activity examples:

- database cleanup
- data model update
- code change
- migration workflow change
- data quality issue found
- data quality issue fixed
